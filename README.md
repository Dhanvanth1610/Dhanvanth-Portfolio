## ✦ What is this?

A personal portfolio that reimagines a GitHub profile as an **animated dark interface**. One HTML file, no framework, no build step. Open it and it runs.

> **Dhanvanth SenthilKumar** · pre-final-year B.Tech, AI & Data Science · Dr. N.G.P. Institute of Technology, Coimbatore
> Published at **ICACIT 2025** · Joint Secretary, Dept. of AI & DS Association

## ✦ Highlights

| | |
|---|---|
| 🌌 **Living background** | Canvas particle field, mouse-tracking spotlight cards, a tilting profile card |
| 🗂️ **11 repositories** | Every card opens its repo, with search plus language and domain filters |
| 📅 **Rolling activity grid** | The contribution map and date roll forward every day |
| 📄 **Resume built in** | Education, projects, skills and achievements, plus a one-click PDF download |
| 🎓 **Certificates** | Filterable by Courses, Projects, Participation and Certification |
| 🎨 **Accent switcher** | Five accent colours, remembered between visits |
| ⌨️ **Keyboard first** | `1` Home · `2` Profile · `3` Repositories · `4` Contact · `/` search |
| ✉️ **Contact flow** | Compose a hiring message and send it via Gmail, your mail app, or an optional form backend |

## ✦ Run it

```bash
git clone https://github.com/Dhanvanth1610/Dhanvanth-Portfolio.git
cd Dhanvanth-Portfolio
python3 -m http.server 8000     # then open http://localhost:8000
```

Or just double-click `index.html`.

<details>
<summary><b>🚀 Publish with GitHub Pages</b></summary>

<br>

Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch `main`, folder `/ (root)` → **Save**.
The site goes live at `https://dhanvanth1610.github.io/Dhanvanth-Portfolio/` after a minute.

</details>

<details>
<summary><b>✉️ Make the contact form deliver straight to your inbox</b></summary>

<br>

1. Create a free form at [formspree.io](https://formspree.io) pointing to your email.
2. In `index.html`, set `var ENDPOINT = "https://formspree.io/f/xxxxxxx";`.
3. A **Send message** button now appears next to the Gmail and mail-app buttons.

</details>

<details>
<summary><b>🛠️ Keep it up to date</b></summary>

<br>

- Repos, certificates and resume text live in the `REPOS`, `CERTS` and resume data inside the `<script>` block of `index.html`.
- Replace `Dhanvanth_Resume.pdf` to update the download.

</details>
